# Aspire Template Installation/Update

Before starting, make sure you are on the latest Aspire templates

```` powershell
dotnet new install Aspire.ProjectTemplates
````

>[!Note]
>Visual studio is very "fun".  Restart your machine after running this if you have any issues running the code that is provided.  It was build, tested, and verified against 13.5.3 Aspire templates.
